# 实验:文本对抗样本 (Text Adversarial Examples)

> 模块 `07` 阶段 2.1,**AI 内生安全**第一个实验。攻击的是**模型本身**(而非提示层):
> 给文本加一点人眼几乎无感的扰动,就能让真实的机器学习分类器判错;再用**对抗训练**让模型自身变鲁棒。
> 对应 MITRE ATLAS(对抗 ML 战术)/ OWASP ML Top 10。

## 与"提示注入/越狱"的区别

| | 提示注入/越狱(模块 02/03) | 对抗样本(本实验) |
|--|--|--|
| 攻击层面 | 应用/提示层(用语言操控大模型) | **模型层**(扰动输入特征让分类器判错) |
| 典型场景 | 让 LLM 泄密/越权 | 让垃圾/违规内容**绕过检测模型** |
| 防御核心 | 输入护栏、权限审计 | **对抗训练**(加固模型本身)、输入规范化 |

> 这就是"内生安全":不在外面加护栏,而是让**模型自身**更难被骗。

## 1. 原理

机器学习分类器靠"特征"判断。文本分类器常用字符/词的 n-gram 特征。
攻击者只要**轻微扰动这些特征**——形近字替换、拆字加分隔符、同义改写——
就能在**人类语义不变**的前提下,让模型的判断翻转。这种输入就叫**对抗样本**。

本实验:训练一个垃圾短信分类器(字符 2-3 元组 TF-IDF + 逻辑回归),
然后用"形近字(简→繁)+ 插入分隔符"把垃圾短信变成对抗样本骗过它。

## 3. 实测结果

| 步骤 | 文本 | 模型判定 |
|------|------|----------|
| 干净垃圾短信 | 免费领取大奖点击链接 | 垃圾(0.63)✓ |
| **对抗样本** | 免·費·領·取·大·獎·點·擊·鏈·接 | **正常(0.49)— 绕过成功** |
| 防御A 规范化后 | (还原)免费领取大奖点击链接 | 垃圾(0.63)✓ |
| 防御B 对抗训练 | 免·費·領·取·大·獎·點·擊·鏈·接 | 垃圾(0.78)✓ 模型自身识别 |

## 4. 防护方案

1. **对抗训练(治本)**:把对抗样本加进训练集重训,让模型对这类扰动鲁棒。这是内生安全的核心手段。
2. **输入规范化(治标)**:分类前统一形近字、去分隔符/空白。简单有效,但需穷举变体,易被新花样绕过。
3. **特征鲁棒化**:用更抗扰动的表示(如语义 embedding)替代脆弱的字符匹配。
4. **多模型集成 / 不确定性拒识**:对低置信度样本转人工。

## 5. 检测清单

- [ ] 输入是否含异常分隔符、零宽字符、形近/繁简混用?
- [ ] 同一语义的轻微变体,模型预测是否剧烈波动(对抗脆弱性信号)?
- [ ] 训练流程是否包含对抗样本增强?
- [ ] 关键检测模型是否定期用对抗变体做红队评测?

## 安全边界

全部在本地、自有数据集上进行,用于防御研究,不针对任何真实第三方系统或模型。
