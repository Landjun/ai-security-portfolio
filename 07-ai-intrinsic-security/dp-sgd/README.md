# 实验:差分隐私训练 DP-SGD (Differentially Private SGD)

> 模块 `07` 阶段 2.x · AI 内生安全 · **隐私防御(研究向)**。闭环 [成员推断攻击](../membership-inference/):用 DP-SGD 从训练阶段保护隐私,并量化"隐私-效用权衡"。
> 纯 numpy 手写 DP-SGD(逐样本梯度裁剪 + 高斯噪声),对应 Abadi et al. 2016 / 隐私合规。

## 1. 原理

[成员推断](../membership-inference/)告诉我们:模型对训练样本过度自信会泄露隐私。
**DP-SGD** 从训练阶段根治,在每个 mini-batch 上做两步:

1. **逐样本梯度裁剪**:把每条样本的梯度 L2 范数裁到不超过 `C` —— 限制任何单条样本对模型的最大影响。
2. **加高斯噪声**:给裁剪后的梯度之和加 `N(0, (σC)²)` 噪声 —— 掩盖"某条样本是否参与训练"。

噪声系数 `σ` 越大,隐私越强(ε 预算越小),但模型效用(准确率)越低。

## 3. 实测结果:隐私-效用权衡

| 训练方式 | 测试准确率(效用) | 成员推断 AUC(隐私) |
|----------|:---:|:---:|
| 非私有(基线) | 81% | 0.58 |
| DP-SGD σ=1.0 | 85% | 0.61 |
| DP-SGD σ=2.0 | 80% | 0.59 |
| DP-SGD σ=4.0 | 73% | 0.54 |
| DP-SGD σ=8.0 | **63%** | **0.51** |

> 解读:
> - **小噪声(σ≤1)** 影响甚微(且有随机波动),几乎不提供隐私。
> - **强噪声(σ=8)** 把成员推断 AUC 压到 0.51(≈随机=几乎不泄露),
>   但准确率从 81% 降到 63% —— 这就是隐私的代价。
> - 这条曲线就是部署隐私模型时要权衡的核心:**隐私越强,效用越低。**

## ★ 关键洞察:隐私不是免费的

DP-SGD 用数学保证("单条样本对模型影响有界")换取隐私,代价是准确率下降。
工程上需要根据场景选 ε 预算:**敏感数据(医疗/金融)宁可牺牲一些准确率换强隐私;
低敏感场景可放宽。** 没有银弹,只有权衡。

## 4. 防护方案(隐私工程)

1. **DP-SGD**(本实验):训练阶段加裁剪+噪声,提供形式化隐私保证。
2. **控制训练步数**:隐私预算随步数消耗,步数越多隐私越弱(本实验也验证了多轮会让噪声失效)。
3. **抑制过拟合**:正则化、早停本身也降低成员推断风险(见成员推断实验)。
4. **输出端**:置信度脱敏、只回 Top-label,削弱攻击信号。
5. **数据最小化 + 查询限制**:从源头减少可泄露的隐私面。
