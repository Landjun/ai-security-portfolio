# 07 · AI 内生安全 (AI Intrinsic / Endogenous Security)

> **核心差异化模块**。研究 AI 模型**本身**的安全——不是应用层提示词,而是模型的训练、参数、推理层面的攻防。这是"AI 内生安全"岗位最看重的能力。

## 计划中的实验(阶段 2)

每个项目 = 一个可复现实验(攻击) + 防御方案 + 面试表达。

- [x] **2.1 文本对抗样本**:对文本分类器做对抗扰动(形近字/拆字),并用对抗训练防御 — ✅ [已完成](text-adversarial/)
- [ ] **2.2 数据投毒**:训练集注入毒样本影响模型,演示检测与清洗
- [ ] **2.3 后门/木马攻击**:带触发器的后门模型,演示触发与后门检测
- [ ] **2.4 成员推断 / 隐私**:判断样本是否在训练集中,讨论差分隐私防御
- [ ] **2.5 模型窃取**:查询蒸馏复制模型,讨论限流/水印防御
- [ ] **2.6 自动化红队**:批量生成越狱/注入变体,给模型安全打分(benchmark)

## 对应威胁框架

- OWASP ML Top 10 / OWASP LLM Top 10(LLM03 数据投毒、LLM10 模型窃取等)
- MITRE ATLAS(AI 系统对抗战术与技术知识库)

## 前置依赖

需要先具备模块 `06` 的真实模型开发/训练能力。建议先完成 `06` 的 1.1/1.4 再进入本模块。

## 安全边界

所有实验仅在**本地、自有模型/数据集**上进行,用于防御研究;不攻击任何第三方真实模型或服务。
