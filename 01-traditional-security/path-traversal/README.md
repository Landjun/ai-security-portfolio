# 案例:路径穿越 (Path Traversal)

> `01 传统安全` 案例。本地临时目录靶场,演示 `../` 跳出目录读取机密文件及防御。对应 OWASP Top 10 A01:Broken Access Control。

## 1. 原理

应用用用户输入拼接文件路径时,攻击者用 `../` 跳出预期目录,读取任意文件
(配置、密钥、`/etc/passwd` 等)。本演示在本地临时目录构造:`public/`(公开)
+ 外层 `secret.txt`(机密),用 `../secret.txt` 越界读取。

## 2. 复现环境

纯本地临时目录,完全无害(运行时自动创建)。
```
path-traversal/
├── demo.py    # 不安全(直接拼接) vs 安全(规范化+边界校验)
└── README.md
```

## 3. 防护方案

1. **规范化 + 边界校验**(首选):`realpath` 解析后,确认最终路径仍在允许的根目录内。
2. **白名单/映射**:用 ID 映射到文件,而非让用户直接传文件名/路径。
3. **拒绝可疑字符**:过滤 `..`、绝对路径、空字节(辅助手段)。
4. **最小权限**:进程只对必要目录有读权限。

## 4. 修复建议

- 所有"按用户输入读文件"的地方加 realpath + 根目录前缀校验。
- 优先用资源 ID 映射,避免暴露真实路径。
- 运行账号最小化文件系统权限。

## 5. 检测清单

- [ ] 是否存在用用户输入拼接文件路径的读/写?
- [ ] 是否对最终路径做了根目录边界校验?
- [ ] 是否用 ID 映射代替直接路径?
- [ ] 进程文件权限是否最小化?

## 6. 面试表达

> "我用本地临时目录复现了路径穿越:不安全的代码把用户传的文件名直接拼到公开目录后面,我传 `../secret.txt` 就跳出目录读到了机密文件;安全版先 realpath 规范化,再校验最终路径仍在公开目录内,越界就拒绝,而正常文件仍可读。核心是'规范化后做根目录边界校验',对应 OWASP A01 访问控制。"

## 运行 & 验证

```powershell
cd 01-traditional-security\path-traversal
python demo.py
```
预期:不安全版读到外层机密文件;安全版拦截穿越、正常文件仍可读。

## 安全边界
