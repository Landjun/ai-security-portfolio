# 三元表达式与链式比较

## 三元表达式(条件表达式)怎么写?
一行写简单的 if-else,常用于赋值:
```
age = 20
status = "成年" if age >= 18 else "未成年"
```
结构:`值A if 条件 else 值B`,条件为真取 A,否则取 B。

## 什么时候用三元表达式?
逻辑简单(二选一)时用,代码更紧凑。逻辑复杂还是用普通 if-else,别硬塞一行。

## 链式比较是什么?
Python 支持把多个比较连起来:
```
if 60 <= score < 90:        # 等价于 score>=60 and score<90
    print("良好")
```
比写 `score >= 60 and score < 90` 更简洁直观。

## 列表推导里的条件?
```
[x if x > 0 else 0 for x in nums]    # 三元在推导式里:负数变0
[x for x in nums if x > 0]           # 过滤:只留正数
```
注意:带 else 的三元放在 for 前面;只过滤(无 else)放在 for 后面。

## and/or 的"短路"特性?
`a and b`:a 为假就不看 b;`a or b`:a 为真就不看 b。可用于安全取值:
`name = user.get("name") or "匿名"`。
