# 调试技巧

## 代码出错了怎么排查?
1. **读报错**:从最后一行看错误类型和说明,看 line 行号定位位置。
2. **打印中间值**:在可疑处加 `print(变量)`,确认实际值和预期是否一致。
3. **缩小范围**:把代码拆开分段运行,定位是哪一行出问题。

## print 调试有什么技巧?
打印时带上变量名,方便分辨:
```
print(f"x = {x}, type = {type(x)}")
```
Python 3.8+ 可用 `print(f"{x=}")`,自动输出 `x=值`。

## 怎么用断点调试?
VS Code / PyCharm 里点行号左边设断点,按调试运行,程序会在断点暂停,
可逐行执行并查看每个变量的当前值,比 print 更高效。

## 程序卡住不动怎么办?
多半是死循环或在等待输入。按 `Ctrl + C` 中断,然后检查循环条件、
是否有 input() 在等待你输入。

## 怎么高效搜索报错?
把报错最后一行(错误类型 + 关键信息)复制去搜索,去掉自己的变量名/路径,
绝大多数常见报错都有现成解决方案。
