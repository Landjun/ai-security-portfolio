# 爬虫数据存储(CSV / JSON / SQLite)

## 爬到的数据存哪?
小规模存文件(CSV/JSON),结构化大规模或要查询用数据库(SQLite 最轻量)。

## 存成 CSV?
用 Pandas 最方便:
```
import pandas as pd
df = pd.DataFrame(records)          # records 是字典列表
df.to_csv("data.csv", index=False, encoding="utf-8-sig")
```
`utf-8-sig` 让 Excel 打开不乱码。也可用标准库 csv 模块逐行写。

## 存成 JSON?
```
import json
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(records, f, ensure_ascii=False, indent=2)
```

## 存进 SQLite(标准库,无需安装)?
```
import sqlite3
conn = sqlite3.connect("data.db")
conn.execute("CREATE TABLE IF NOT EXISTS items(name TEXT, price REAL)")
conn.executemany("INSERT INTO items VALUES(?,?)",
                 [(it["name"], it["price"]) for it in records])
conn.commit(); conn.close()
```
注意用参数化 `?` 写入,避免 SQL 注入。

## 边爬边存,防止中途丢数据?
每爬一批就追加写入(CSV 用 mode="a"),或定期 commit 数据库,
配合"记录已爬 URL"做断点续爬。

## 怎么去重?
存之前用集合记录已见过的唯一标识(如 URL/ID),或入库后用 Pandas drop_duplicates。
