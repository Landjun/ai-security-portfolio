# 数据分析常见报错

## ModuleNotFoundError: No module named 'pandas'
没装库。`pip install pandas numpy matplotlib openpyxl`。
注意要装在当前用的环境/解释器里(用 Jupyter 时尤其常见装错环境)。

## 读 CSV 中文乱码怎么办?
指定编码:`pd.read_csv("data.csv", encoding="utf-8")`;
若仍乱码,文件可能是 GBK,改 `encoding="gbk"`。

## SettingWithCopyWarning
对筛选出的切片直接赋值引发的警告。规范做法:用 `df.loc[条件, "列"] = 值` 一次定位赋值,
或先 `.copy()` 再修改。

## KeyError: '列名'
列名写错或该列不存在。用 `df.columns` 查看真实列名(注意有没有多余空格、大小写)。

## ValueError: could not convert string to float
某列里混入了非数字(如空字符串、中文)。先清洗:
`pd.to_numeric(df["列"], errors="coerce")` 把无法转换的变成 NaN 再处理。

## 形状/维度不匹配(shape mismatch)
NumPy 运算时两个数组形状不兼容。打印各自 `.shape` 检查,必要时用 reshape 调整。

## Matplotlib 图不显示?
脚本里记得调用 `plt.show()`;在某些环境(无界面服务器)需保存为图片 `plt.savefig()`。
