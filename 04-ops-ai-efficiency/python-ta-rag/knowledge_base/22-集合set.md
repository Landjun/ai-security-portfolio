# 集合 set

## 集合是什么?怎么创建?
集合是**无序、不重复**的容器,用花括号或 set():
```
s = {1, 2, 3}
s2 = set([1, 1, 2])   # {1, 2},自动去重
empty = set()          # 空集合(注意:{} 是空字典,不是空集合)
```

## 集合的主要用途?
- **去重**:`list(set(列表))` 快速去掉列表里的重复元素。
- **快速判断是否存在**:`if x in s:` 比在列表里查更快。

## 集合常用操作?
- 增:`s.add(4)`;删:`s.remove(2)`(不存在会报错)或 `s.discard(2)`(不存在不报错)。
- 交集:`a & b`;并集:`a | b`;差集:`a - b`。

## 集合能放列表吗?
不能。集合元素必须是不可变类型(数字、字符串、元组),不能放列表或字典。

## 集合有序吗?能用下标取吗?
无序,不能用 `s[0]` 取元素。需要顺序就用列表。
