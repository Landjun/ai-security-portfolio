# Pandas 分组统计

## groupby 是干什么的?
按某列分组,再对每组做统计(求和、平均、计数等),类似 Excel 数据透视。
```
# 按班级统计平均分
df.groupby("班级")["分数"].mean()

# 按班级统计人数
df.groupby("班级").size()
```

## 怎么对多个指标聚合?
```
df.groupby("班级").agg({
    "分数": "mean",
    "姓名": "count",
})
```

## 常用聚合函数有哪些?
mean(均值)、sum(求和)、count(计数)、max/min(最值)、median(中位数)、std(标准差)。

## 怎么统计某列每个值出现的次数?
```
df["班级"].value_counts()
```
常用于快速看分布(比如每个班多少人)。

## 分组后想还原成普通表怎么办?
在末尾加 `.reset_index()`,把分组键变回普通列,便于继续处理或导出。
