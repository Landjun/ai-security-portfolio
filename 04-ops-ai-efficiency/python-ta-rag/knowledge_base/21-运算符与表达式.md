# 运算符与表达式

## 算术运算符有哪些?
`+ - * /` 加减乘除;还有几个新手常忘的:
- `//` 整除(取商的整数部分):`7 // 2` 得 3。
- `%` 取余(取模):`7 % 2` 得 1,常用于判断奇偶。
- `**` 幂运算:`2 ** 3` 得 8。

## / 和 // 有什么区别?
`/` 永远返回浮点数:`6 / 2` 得 3.0;`//` 取整:`6 // 2` 得 3。

## 比较和逻辑运算符?
- 比较:`== != > < >= <=`,返回 True/False。注意判断相等是两个等号 `==`,一个 `=` 是赋值。
- 逻辑:`and`(且)、`or`(或)、`not`(非)。例如 `if a > 0 and b > 0:`。

## += 这类是什么?
复合赋值:`x += 1` 等价于 `x = x + 1`;同理还有 `-= *= /= //= %=`。

## 怎么判断一个数是偶数?
`if n % 2 == 0:` 余数为 0 即偶数。
