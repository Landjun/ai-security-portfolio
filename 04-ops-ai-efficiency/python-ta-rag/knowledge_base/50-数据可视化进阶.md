# 数据可视化进阶

## 常见图表分别适合什么?
- 折线图:看趋势(随时间变化)。
- 柱状图:比较不同类别的数量。
- 饼图:看占比构成。
- 散点图:看两个变量的关系。
- 直方图:看数据分布。

## 用 Pandas 快速画图?
```
df["薪资"].plot(kind="hist")              # 直方图
df.groupby("城市")["薪资"].mean().plot(kind="bar")   # 分组后柱状图
```

## 让图更好看用 seaborn?
`pip install seaborn`,基于 matplotlib,默认样式更美观:
```
import seaborn as sns
sns.barplot(data=df, x="城市", y="薪资")
sns.heatmap(df.corr(), annot=True)        # 相关性热力图
```

## 中文/负号显示异常怎么办?
```
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False
```

## 怎么把图保存出来?
`plt.savefig("result.png", dpi=150, bbox_inches="tight")`(在 show 之前调用,bbox 防止标签被裁掉)。

## 可视化 + AI 建议的思路?
把清洗统计后的数据(如各行业薪资、考研分布)整理成文字摘要,连同问题一起发给大模型,
让它给出趋势解读和建议——这就是"数据 + AI"的常见提效组合。
