# 异常处理 try/except

## try/except 怎么用?
用来捕获并处理可能出错的代码,避免程序直接崩溃:
```
try:
    age = int(input("输入年龄:"))
    print(100 / age)
except ValueError:
    print("请输入数字")
except ZeroDivisionError:
    print("年龄不能为 0")
```

## except 后面要不要写具体错误类型?
建议写具体类型(如 ValueError),只捕获你预期的错误。
裸 `except:` 会吞掉所有异常(包括你没想到的 bug),不利于排查,不推荐。

## finally 是做什么的?
不管有没有出错都会执行,常用于收尾(关闭文件、释放资源):
```
try:
    ...
finally:
    print("无论如何都会执行")
```

## 什么时候用异常处理?
处理"可能失败但你想优雅应对"的场景(用户输入、文件、网络)。
不要用异常代替正常的逻辑判断(比如能用 if 判断的就别靠报错)。
