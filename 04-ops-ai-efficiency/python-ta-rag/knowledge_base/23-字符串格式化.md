# 字符串格式化

## 推荐用哪种格式化方式?
首选 f-string(Python 3.6+),最简洁:
```
name, score = "小明", 95.5
print(f"{name} 考了 {score} 分")
```

## f-string 怎么控制小数位和对齐?
在变量后用冒号加格式说明:
- 保留两位小数:`f"{score:.2f}"` -> 95.50
- 百分比:`f"{0.25:.0%}"` -> 25%
- 宽度对齐:`f"{name:>10}"` 右对齐占 10 位,`<` 左对齐,`^` 居中。
- 数字补零:`f"{7:03d}"` -> 007。

## 还有哪些老式写法?
- `"{} 分".format(score)`(format 方法)。
- `"%.2f" % score`(% 格式化,较老)。
新手统一用 f-string 即可,另两种了解能看懂就行。

## 怎么换行和制表?
字符串里 `\n` 表示换行,`\t` 表示制表符(Tab)。
