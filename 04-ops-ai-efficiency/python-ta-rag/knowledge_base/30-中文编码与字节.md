# 中文编码与字节(str 与 bytes)

## 为什么会出现中文乱码?
读写文件或网络数据时编码不一致导致。Python 3 里文本是 str,
存储/传输是 bytes(字节),两者要按相同编码转换,否则乱码。

## 读文件中文乱码怎么解决?
打开文件时显式指定编码:
```
open("a.txt", encoding="utf-8")
```
Windows 默认可能是 GBK,不写 encoding 容易乱码。统一用 utf-8 最稳妥。

## str 和 bytes 怎么互转?
```
s = "你好"
b = s.encode("utf-8")     # str -> bytes
s2 = b.decode("utf-8")    # bytes -> str
```
编码用 encode,解码用 decode,两边编码要一致。

## UnicodeDecodeError 怎么办?
解码用的编码和文件实际编码不一致。先确认文件是 utf-8 还是 gbk,
用对应编码 decode;不确定时可尝试 `encoding="utf-8"` 或 `"gbk"`。

## 控制台打印中文报错(GBK)怎么办?
Windows 控制台默认 GBK,打印某些字符(如 emoji)会报错。
可设置环境变量 `PYTHONUTF8=1`,或避免在输出里用 emoji。
