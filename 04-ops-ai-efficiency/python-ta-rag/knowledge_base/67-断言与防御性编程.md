# 断言 assert 与防御性编程

## assert 是干什么的?
断言:确认某个条件为真,不为真就立刻报错(AssertionError),用于调试期捕捉"不该发生"的情况:
```
def divide(a, b):
    assert b != 0, "除数不能为 0"
    return a / b
```
条件为假时抛出错误并显示后面的提示信息。

## assert 和 if 判断的区别?
- if 是正常业务逻辑,处理预期内的情况。
- assert 是"自检",验证你认为一定成立的前提;它可被 `python -O` 关闭,
  所以**不要用 assert 做正式的参数校验或安全检查**(生产中应抛具体异常)。

## 什么是防御性编程?
提前考虑"输入可能是错的",做校验和兜底,让程序更健壮:
- 校验输入类型/范围。
- 用 try/except 处理可能的异常。
- 对边界情况(空列表、None、0)做处理。

## 怎么主动抛出异常?
```
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负数")
```
用 raise 抛出合适的异常类型,比让程序在后面莫名其妙崩掉更好排查。

## 新手怎么用?
调试时用 assert 快速验证假设;正式校验用 if + raise 抛明确的异常。
