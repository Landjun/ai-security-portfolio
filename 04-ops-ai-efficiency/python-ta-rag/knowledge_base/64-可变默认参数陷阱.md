# 可变默认参数陷阱(经典坑)

## 这段代码为什么出 bug?
```
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  ← 居然带着上次的!
```
默认参数 `[]` 只在函数定义时创建**一次**,多次调用共享同一个列表,所以会累积。

## 正确写法?
默认值用 None,在函数内部创建新对象:
```
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## 哪些默认参数有这个问题?
所有**可变对象**:列表 []、字典 {}、集合 set()。不可变的(数字、字符串、None、元组)没问题。

## 字典默认参数也一样吗?
是的:
```
def f(config=None):
    if config is None:
        config = {}
    ...
```

## 怎么记住这个坑?
口诀:**默认参数别用可变对象,用 None 占位、进函数再创建。**
