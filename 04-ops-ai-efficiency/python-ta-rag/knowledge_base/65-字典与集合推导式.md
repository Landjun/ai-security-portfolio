# 字典推导式与集合推导式

## 字典推导式怎么写?
一行生成字典:
```
squares = {x: x*x for x in range(5)}        # {0:0, 1:1, 2:4, 3:9, 4:16}
```
结构:`{键: 值 for 变量 in 序列}`。

## 字典推导式的常见用途?
- 反转键值:`{v: k for k, v in d.items()}`
- 过滤:`{k: v for k, v in d.items() if v > 60}`
- 从两个列表组装:`{k: v for k, v in zip(keys, values)}`

## 集合推导式怎么写?
和列表推导式类似,但用花括号,且自动去重:
```
evens = {x for x in range(10) if x % 2 == 0}   # {0,2,4,6,8}
```

## 怎么快速统计词频?
```
words = "a b a c b a".split()
count = {w: words.count(w) for w in set(words)}
```
(数据量大时更推荐用 collections.Counter。)

## 推导式会不会太复杂?
逻辑简单时推导式简洁好读;逻辑复杂(多重嵌套、多条件)时,
写成普通 for 循环反而更清晰,别为了一行硬塞。
