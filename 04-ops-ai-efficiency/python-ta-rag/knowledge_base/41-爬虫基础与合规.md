# 爬虫基础与合规

## 爬虫是什么?
用程序自动访问网页、获取公开数据。本质就是"程序代替人去打开网页、保存内容"。
入门用 requests 库:`pip install requests`。

## 一个最简单的爬虫?
```
import requests
r = requests.get("https://example.com", timeout=5)
r.encoding = "utf-8"
print(r.status_code)   # 200 表示成功
print(r.text[:200])    # 网页 HTML 前 200 字
```

## 必须先看 robots.txt 和使用条款
访问网站根目录的 `/robots.txt`(如 example.com/robots.txt)能看到网站允许/禁止爬取的范围。
**爬取前务必遵守 robots 规则和网站使用条款(ToS)**,这是合规爬虫的第一条。

## 加请求头(User-Agent)
有些网站要求带 UA,模拟正常浏览器访问:
```
headers = {"User-Agent": "Mozilla/5.0 ..."}
requests.get(url, headers=headers, timeout=5)
```

## 合规三原则(务必牢记)
1. **只爬公开、允许爬取的数据**,遵守 robots 与 ToS。
2. **控制频率**(加 `time.sleep()`),不给对方服务器造成压力。
3. **不爬个人隐私、不爬付费/登录后受保护内容、不商用未授权数据**。
详见《爬虫法律与道德红线》一篇。
