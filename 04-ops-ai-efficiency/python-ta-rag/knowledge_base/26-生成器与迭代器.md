# 生成器与迭代器

## 生成器是什么?
一种"用到时才生成、不一次性占满内存"的序列,用 yield 定义:
```
def count_up(n):
    for i in range(n):
        yield i        # 每次产出一个值,暂停在这里

for x in count_up(3):
    print(x)           # 0 1 2
```

## yield 和 return 区别?
return 直接结束函数并返回;yield 产出一个值后**暂停**,下次迭代再从这里继续。
所以生成器适合处理大数据或无限序列,不会一次把所有结果放进内存。

## 生成器表达式怎么写?
和列表推导式类似,但用圆括号,返回生成器(更省内存):
```
gen = (x * x for x in range(1000000))   # 不会立刻算出一百万个数
```

## 什么是迭代器?
能被 for 循环逐个取值的对象。列表、字符串、字典、生成器都可迭代。
用 `next(迭代器)` 手动取下一个;取完会抛 StopIteration。

## 什么时候该用生成器?
数据量大、或只需要逐个处理而不需要全部留在内存时,用生成器更高效。
