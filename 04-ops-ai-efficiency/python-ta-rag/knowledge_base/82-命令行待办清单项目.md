# 命令行待办清单(To-Do)项目

## 这个项目练什么?
列表/字典操作、循环菜单、文件读写持久化——一个很好的综合练习。

## 基本骨架(内存版)?
```
todos = []
while True:
    cmd = input("命令(add/list/done/quit):").strip()
    if cmd == "add":
        todos.append({"task": input("任务:"), "done": False})
    elif cmd == "list":
        for i, t in enumerate(todos):
            mark = "[x]" if t["done"] else "[ ]"
            print(i, mark, t["task"])
    elif cmd == "done":
        i = int(input("完成第几个:"))
        todos[i]["done"] = True
    elif cmd == "quit":
        break
```

## 怎么让数据"重启不丢"(持久化)?
用 JSON 文件存读:
```
import json
# 保存
with open("todos.json", "w", encoding="utf-8") as f:
    json.dump(todos, f, ensure_ascii=False)
# 启动时读取
import os
if os.path.exists("todos.json"):
    with open("todos.json", encoding="utf-8") as f:
        todos = json.load(f)
```

## 可以怎么扩展?
加优先级、截止日期、删除、搜索、按状态筛选。这些扩展正好复习列表/字典/排序/过滤。

## 项目价值
一个能跑、能持久化的小工具,很适合放进作品集,讲清"用到了哪些知识点"。
