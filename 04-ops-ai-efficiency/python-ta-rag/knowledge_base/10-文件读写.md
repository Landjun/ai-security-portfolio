# 文件读写

## 怎么读取一个文本文件?
推荐用 with 语句(自动关闭文件),并指定编码避免中文乱码:
```
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()       # 读全部
```
逐行读:`for line in f:`;读成列表:`f.readlines()`。

## 怎么写入文件?
```
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
```
- 模式 "w":覆盖写(原内容清空);"a":追加写;"r":只读。

## 读中文文件乱码怎么办?
打开时显式加 `encoding="utf-8"`。Windows 上不写编码可能默认 GBK 导致乱码。

## FileNotFoundError 怎么回事?
文件路径不对或文件不存在。检查路径是否正确、是否在当前工作目录下,
可用绝对路径或确认文件确实存在。
