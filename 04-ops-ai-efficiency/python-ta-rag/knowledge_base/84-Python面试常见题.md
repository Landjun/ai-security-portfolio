# Python 面试常见题(概念辨析)

## == 和 is 的区别?
== 比较值是否相等;is 比较是不是同一个对象。判断 None 用 is。

## 列表和元组的区别?
列表 [] 可变,元组 () 不可变。元组更省内存、可作字典键。

## 深拷贝和浅拷贝?
浅拷贝只复制最外层,嵌套对象仍共享;深拷贝(copy.deepcopy)彻底独立。

## 可变和不可变类型?
不可变:数字、字符串、元组;可变:列表、字典、集合。
影响函数传参、默认参数、字典键的选择。

## 什么是装饰器?
不改原函数代码、给它加功能的语法(@),常用于日志、计时、缓存。

## 生成器和列表的区别?
生成器用到才产出、省内存(yield);列表一次性全在内存里。

## *args 和 **kwargs?
*args 收任意位置参数(元组);**kwargs 收任意关键字参数(字典)。

## 怎么交换两个变量?
`a, b = b, a`。

## 列表去重?
`list(set(列表))`(不保序)或用 dict.fromkeys 保序。

## Python 为什么慢?怎么提速?
解释执行、动态类型。提速:用内置函数/NumPy 向量化、减少循环、必要时用并发或 C 扩展。

## 面试建议
概念题背熟之外,更重要的是**能结合你做过的项目举例**,讲清你在哪用过、踩过什么坑。
