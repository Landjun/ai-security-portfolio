# 字符串操作

## 字符串常用方法有哪些?
- `s.strip()` 去掉首尾空白;`s.lower()` / `s.upper()` 大小写转换。
- `s.replace("a", "b")` 替换;`s.split(",")` 按分隔符切成列表;`",".join(列表)` 拼接。
- `s.find("x")` 查找位置(找不到返回 -1);`"x" in s` 判断是否包含。
- `len(s)` 长度;`s[0]` 取第一个字符;`s[-1]` 取最后一个;`s[1:3]` 切片。

## f-string 怎么用(格式化字符串)?
推荐用 f-string,简洁直观:
```
name = "小明"
age = 18
print(f"我叫{name},今年{age}岁")
```
大括号里可以直接写变量或表达式,如 `f"{age + 1}"`。

## 字符串能修改某个字符吗?
不能。字符串是不可变的,`s[0] = "x"` 会报错。要"修改"得生成新字符串,
比如用 replace 或切片拼接。
