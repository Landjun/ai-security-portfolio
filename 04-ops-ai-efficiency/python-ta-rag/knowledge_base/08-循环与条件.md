# 循环与条件判断

## if 条件判断怎么写?
```
if score >= 60:
    print("及格")
elif score >= 40:
    print("补考")
else:
    print("不及格")
```
注意每个分支末尾的冒号,以及代码块的缩进。

## for 循环怎么用?
遍历一个序列:
```
for i in range(5):      # 0,1,2,3,4
    print(i)

for name in ["A", "B"]: # 遍历列表
    print(name)
```
range(n) 生成 0 到 n-1;range(a, b) 生成 a 到 b-1。

## while 循环怎么用?
条件为真时反复执行:
```
n = 0
while n < 3:
    print(n)
    n += 1
```
注意:循环体里要让条件最终变假,否则会死循环。

## break 和 continue 区别?
- break:立即跳出整个循环。
- continue:跳过本次,直接进入下一次循环。

## 循环卡住不动(死循环)怎么办?
按 Ctrl + C 终止程序。然后检查 while 的条件是否永远为真、有没有忘记更新变量。
