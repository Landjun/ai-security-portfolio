# Python 环境安装

## 怎么安装 Python?
到官网 python.org 下载对应系统的安装包(Windows 选 amd64)。安装时**务必勾选
"Add Python to PATH"**,否则命令行里输入 python 会提示找不到命令。

## 怎么确认装好了?
打开命令行(Windows 用 PowerShell 或 cmd),输入:
```
python --version
```
能显示版本号(如 Python 3.12.7)就说明安装成功。

## 提示 "python 不是内部或外部命令" 怎么办?
通常是没有把 Python 加入 PATH。解决:重新运行安装包选择 Modify,勾选 Add to PATH;
或手动把 Python 安装目录和其下 Scripts 目录加进系统环境变量 PATH,然后重开命令行。

## 选 Python 2 还是 Python 3?
一律用 Python 3。Python 2 已停止维护,新手不要用。
