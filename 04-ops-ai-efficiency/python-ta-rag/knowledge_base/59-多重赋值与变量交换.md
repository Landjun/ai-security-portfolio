# 多重赋值与变量交换

## 怎么一次给多个变量赋值?
```
a, b, c = 1, 2, 3        # 同时赋值
x = y = z = 0            # 多个变量赋同一个值
```

## 怎么交换两个变量的值?
Python 一行搞定,不需要临时变量:
```
a, b = b, a
```

## 怎么把列表"拆包"给变量?
```
point = [10, 20]
x, y = point             # x=10, y=20
```
变量个数要和元素个数一致,否则报错。

## 用 * 接收剩余元素?
```
first, *rest = [1, 2, 3, 4]   # first=1, rest=[2,3,4]
a, *mid, b = [1, 2, 3, 4]     # a=1, mid=[2,3], b=4
```

## 遍历时同时拿下标和值?
```
for i, v in enumerate(["a", "b"]):
    print(i, v)
```

## 遍历字典的键值?
```
for k, v in d.items():
    print(k, v)
```
这些都是"拆包"的应用,让代码更简洁。
