# 列表推导式与常用内置函数

## 列表推导式怎么用?
一行生成列表,简洁高效:
```
squares = [x * x for x in range(5)]        # [0,1,4,9,16]
evens = [x for x in range(10) if x % 2 == 0]  # 带条件过滤
```
等价于写 for 循环 append,但更简洁。

## 常用内置函数有哪些?
- `len(x)` 长度;`sum(列表)` 求和;`max()` / `min()` 最大最小值。
- `sorted(列表)` 排序(返回新列表);`列表.sort()` 原地排序。
- `range(n)` 生成数字序列;`enumerate(列表)` 同时拿下标和值。
- `zip(a, b)` 把两个列表配对。

## enumerate 怎么用?
遍历时同时拿到下标和元素:
```
for i, name in enumerate(["A", "B"]):
    print(i, name)   # 0 A / 1 B
```

## map 和 filter 是什么?
- `map(函数, 列表)` 对每个元素应用函数。
- `filter(函数, 列表)` 保留函数返回 True 的元素。
新手用列表推导式通常更直观,二者可互相替代。
