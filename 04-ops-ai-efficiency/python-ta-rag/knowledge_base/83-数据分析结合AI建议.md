# 数据分析 + AI 给建议

> 对应"考研数据 + AI 专家建议""薪资趋势 + AI 预测"这类项目:先用 Python 把数据
> 清洗统计好,再把结果交给大模型生成解读和建议。

## 整体流程?
1. 爬取/读取数据(合规公开数据)。
2. 用 Pandas 清洗、分组、统计出关键指标。
3. 把指标整理成一段**文字摘要**。
4. 把摘要 + 你的问题发给大模型,让它给解读/建议。
5. 人工审核 AI 的输出再使用。

## 怎么调用大模型 API?
以 OpenAI 兼容接口(如 DeepSeek)为例:
```
from openai import OpenAI
client = OpenAI(api_key="你的key", base_url="https://api.deepseek.com")
summary = "各专业平均分:计算机380,法学350……"   # 来自 Pandas 统计
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user",
               "content": f"根据以下考研数据给出报考建议:\n{summary}"}],
)
print(resp.choices[0].message.content)
```

## API Key 怎么安全管理?
放进 .env 文件用 python-dotenv 读取,**绝不要写死在代码里、也不要提交到 GitHub**:
```
DEEPSEEK_API_KEY=sk-xxxx        # .env 文件,加入 .gitignore
```

## 让 AI 输出更靠谱的技巧?
- 把"事实数据"放进 prompt(数据驱动),别让它凭空编。
- 让它"基于给定数据"回答,数据没有就说不知道。
- 关键结论人工复核,AI 给的是参考不是定论。

## 这类项目为什么加分?
它体现"数据能力 + AI 应用"的结合,是很受欢迎的实战方向,也很适合放进作品集讲故事。
