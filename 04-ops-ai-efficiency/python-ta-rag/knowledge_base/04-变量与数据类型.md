# 变量与数据类型

## Python 有哪些基本数据类型?
- 整数 int(如 10)、浮点数 float(如 3.14)、字符串 str(如 "hello")、布尔 bool(True/False)。
- 容器类型:列表 list、元组 tuple、字典 dict、集合 set。

## 怎么查看一个变量的类型?
用 `type(变量)`,例如 `type(x)`。也可用 `isinstance(x, int)` 判断是否为某类型。

## 字符串和数字怎么互相转换?
- 字符串转数字:`int("10")`、`float("3.14")`。
- 数字转字符串:`str(10)`。
注意:`"10" + 5` 会报 TypeError,因为字符串不能直接和数字相加,要先转换类型。

## input() 拿到的是什么类型?
input() 返回的永远是字符串。要做数学运算需先转换,例如:
```
age = int(input("请输入年龄:"))
```
