# 装饰器入门

## 装饰器是什么?
一种"在不改动原函数代码的前提下,给它增加功能"的写法,用 @ 语法。
常见用途:打日志、计时、权限校验、缓存。

## 一个最简单的装饰器例子?
```
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        result = func(*args, **kwargs)
        print("调用结束")
        return result
    return wrapper

@log
def hello():
    print("hello")

hello()   # 会打印:调用 hello / hello / 调用结束
```

## @log 这一行是什么意思?
`@log` 等价于 `hello = log(hello)`,即把 hello 包进 wrapper,
之后调用 hello() 实际执行的是带了额外功能的 wrapper。

## *args, **kwargs 在装饰器里干嘛?
让 wrapper 能接收并转发原函数的任意参数,使装饰器能适配各种函数。

## 内置常用装饰器?
`@staticmethod`、`@classmethod`、`@property`(类里用),`functools.lru_cache`(加缓存)。
