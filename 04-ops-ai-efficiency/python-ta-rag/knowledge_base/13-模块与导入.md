# 模块与导入

## 怎么导入模块?
```
import math            # 导入整个模块,用 math.sqrt(4)
from math import sqrt  # 只导入 sqrt,直接用 sqrt(4)
import numpy as np     # 起别名,用 np.array(...)
```

## 怎么导入自己写的 .py 文件?
把两个 .py 放在同一目录,在 a.py 里 `import b` 即可使用 b.py 里的函数/变量
(用 `b.函数名()`)。注意模块名就是文件名去掉 .py。

## ModuleNotFoundError 怎么办?
- 第三方库:`pip install 库名` 安装,注意要装在当前用的环境里。
- 自己的文件:确认文件名拼写、是否在同一目录或正确的路径下。

## if __name__ == "__main__": 是什么意思?
判断"这个文件是被直接运行,还是被当作模块导入"。直接运行时 __name__ 等于
"__main__",这段代码才执行;被别的文件 import 时不执行。常用来放测试/入口代码。
