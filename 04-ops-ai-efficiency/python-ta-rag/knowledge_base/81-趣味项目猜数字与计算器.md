# 趣味项目:猜数字与计算器

## 猜数字游戏怎么做?
随机数 + 循环 + 条件判断的经典练习:
```
import random
answer = random.randint(1, 100)
while True:
    guess = int(input("猜一个 1-100 的数:"))
    if guess == answer:
        print("猜对了!")
        break
    elif guess < answer:
        print("小了")
    else:
        print("大了")
```
进阶:加猜测次数限制、记录最少次数。

## 简易计算器怎么做?
```
a = float(input("第一个数:"))
op = input("运算符 (+ - * /):")
b = float(input("第二个数:"))

if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    print(a / b if b != 0 else "除数不能为0")
else:
    print("不支持的运算符")
```

## 这些小项目练什么?
输入处理、类型转换、条件分支、循环、异常处理。把这几样练熟,
后面做爬虫、数据分析就是它们的组合。

## 怎么让程序更健壮?
对用户输入做校验(用 try/except 防止输入非数字崩溃),给出友好提示。
