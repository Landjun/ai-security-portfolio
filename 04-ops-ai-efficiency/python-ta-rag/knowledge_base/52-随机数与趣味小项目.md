# 随机数与趣味小项目(抽卡/检测器/重启系统)

> 课程里的"盲盒抽卡、恋爱缘分检测器、人生重启系统"这类小项目,核心就是
> 随机数 + 条件判断 + 循环 + 函数,是练基础的好方式。

## 怎么生成随机数/随机选择?
```
import random
random.randint(1, 100)        # 1到100的随机整数
random.random()               # 0~1 的随机小数
random.choice(["金", "银", "铜"])     # 随机取一个
random.choices(["R","SR","SSR"], weights=[80,18,2])  # 按概率抽(抽卡核心)
random.shuffle(列表)           # 洗牌(原地打乱)
```

## 盲盒抽卡系统的思路?
用 `random.choices` 按权重抽稀有度,循环模拟多次抽卡,统计各稀有度数量:
```
import random
pool = ["N", "R", "SR", "SSR"]
weights = [50, 35, 13, 2]
for _ in range(10):
    print(random.choices(pool, weights=weights)[0])
```

## "检测器/缘分值"这类怎么做?
本质是输入 + 随机/规则计算 + 输出。注意:这是**娱乐**,不是真预测,讲清逻辑即可:
```
import random
name = input("名字:")
print(f"{name} 的今日缘分值:{random.randint(0,100)}")
```

## "人生重启/文字游戏"的骨架?
用循环 + 条件 + 随机事件推进剧情:
```
import random
age = 0
while age < 100:
    event = random.choice(["升职", "中奖", "感冒", "旅行"])
    print(f"{age}岁:{event}")
    age += random.randint(1, 10)
```

## 想每次结果可复现怎么办?
`random.seed(42)` 固定随机种子,适合调试和教学演示。
