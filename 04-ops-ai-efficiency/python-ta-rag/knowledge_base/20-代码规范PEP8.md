# 代码规范 PEP8

## 为什么要讲代码规范?
统一的风格让代码更易读、易维护,也是团队协作和面试中的基本素养。
Python 官方风格指南叫 PEP8。

## 命名规范怎么写?
- 变量、函数:小写 + 下划线,如 `user_name`、`get_score()`。
- 常量:全大写,如 `MAX_SIZE`。
- 类名:大驼峰,如 `StudentInfo`。
- 不要用拼音、单字母(循环变量除外)、与内置同名(如 list、str)。

## 缩进和空格?
- 用 4 个空格缩进,不用 Tab。
- 运算符两侧加空格:`a = b + c`,不是 `a=b+c`。
- 逗号后加空格:`f(a, b)`。

## 一行太长怎么办?
建议每行不超过 79~100 字符。过长可换行或拆分逻辑。

## 有工具能自动检查/格式化吗?
- `black` 自动格式化代码:`pip install black` 后 `black 文件.py`。
- `flake8` / `pylint` 检查规范问题。
新手养成用格式化工具的习惯,代码立刻整洁很多。
