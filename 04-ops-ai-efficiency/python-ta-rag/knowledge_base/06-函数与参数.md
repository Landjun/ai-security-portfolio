# 函数与参数

## 怎么定义和调用函数?
用 def 定义:
```
def greet(name):
    return "你好, " + name

print(greet("小明"))   # 调用,输出 你好, 小明
```

## return 和 print 有什么区别?
- print 只是把内容打印到屏幕,函数本身没有"返回值"。
- return 是把结果交回给调用处,可以被变量接收、继续参与计算。
新手常见误区:函数里只 print 不 return,然后用变量接收却得到 None。

## 默认参数、关键字参数是什么?
- 默认参数:`def f(x, y=10):`,调用时不传 y 就用默认 10。
- 关键字参数:`f(x=1, y=2)`,按名字传,顺序无所谓。
注意:默认参数必须放在普通参数后面。

## *args 和 **kwargs 是什么?
- `*args` 接收任意数量的位置参数,变成元组。
- `**kwargs` 接收任意数量的关键字参数,变成字典。
用于参数个数不确定的场景。
