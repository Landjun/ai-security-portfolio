# 类型转换大全

## 常用类型转换函数?
- `int(x)`:转整数。`int("10")`→10;`int(3.9)`→3(直接截断,不四舍五入)。
- `float(x)`:转浮点。`float("3.14")`→3.14。
- `str(x)`:转字符串。`str(100)`→"100"。
- `bool(x)`:转布尔。空值/0 为 False。

## 容器之间怎么转?
- `list("abc")`→['a','b','c'];`list((1,2))`→[1,2]。
- `tuple([1,2])`→(1,2)。
- `set([1,1,2])`→{1,2}(去重)。
- `dict([("a",1)])`→{'a':1}。

## 四舍五入怎么做?
`round(3.567, 2)`→3.57(保留两位)。注意 int() 是截断不是四舍五入。

## 字符串和数字相加报错怎么办?
`"10" + 5` 会报 TypeError。要么都转成数字相加,要么都转成字符串拼接:
```
int("10") + 5          # 15
"10" + str(5)          # "105"
```

## 转换失败会怎样?
`int("abc")` 会抛 ValueError。不确定能否转换时,用 try/except 包起来处理。

## 进制转换?
`bin(10)`→'0b1010';`hex(255)`→'0xff';`int("ff", 16)`→255。
