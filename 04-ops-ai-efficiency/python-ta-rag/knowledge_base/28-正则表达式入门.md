# 正则表达式入门

## 正则是干什么的?
按"模式"匹配/查找/替换文本,常用于校验格式(手机号、邮箱)、提取信息。Python 用 `re` 模块。

## 基本用法?
```
import re

# 查找第一个匹配
m = re.search(r"\d+", "订单12345")
print(m.group())     # 12345

# 找出所有匹配
print(re.findall(r"\d+", "a1b22c333"))   # ['1', '22', '333']

# 替换
print(re.sub(r"\d", "*", "abc123"))       # abc***
```

## 常用元字符?
- `\d` 数字,`\w` 字母数字下划线,`\s` 空白。
- `.` 任意字符,`*` 零或多个,`+` 一或多个,`?` 零或一个。
- `^` 开头,`$` 结尾,`[abc]` 其中之一,`{2,4}` 出现 2 到 4 次。

## 为什么要用 r"" 原始字符串?
正则里反斜杠很多,`r"\d"` 能避免和 Python 转义冲突,写正则一律加 r 前缀。

## 简单校验手机号?
```
re.match(r"^1[3-9]\d{9}$", "13812345678")   # 匹配成功返回对象,否则 None
```
