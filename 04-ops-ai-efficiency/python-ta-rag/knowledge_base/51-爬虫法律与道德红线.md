# 爬虫法律与道德红线(必读)

> 学爬虫,技术之外更要懂边界。这一篇是底线,遇到"逆向、破解、采集付费/登录内容"
> 这类问题,答案都在这里:**优先合规渠道,不要绕过访问控制。**

## 可以爬什么?
- 网站**公开、允许爬取**(robots.txt 允许)的数据。
- 数据量小、频率低、仅用于个人学习与练习。
- 网站提供的**官方开放 API**(最推荐,稳定又合规)。

## 绝对不要做的事(法律红线)
- **绕过访问控制**:破解登录验证、验证码、加密签名(sign)、付费墙等。
- **采集付费/会员(VIP)内容**:这类内容受访问控制和著作权保护。
- **抓取个人隐私信息**:手机号、身份证、住址等(违反《个人信息保护法》)。
- **高频访问致对方服务受影响**:可能构成破坏。
- **未授权商用**:把爬来的数据用于商业牟利。

## 涉及的法律(了解即可)
- 《刑法》第 285 条:非法获取计算机信息系统数据罪——绕过保护措施获取数据可能触刑。
- 《著作权法》:小说、图片、音视频、付费内容多受版权保护。
- 《个人信息保护法》《数据安全法》:严禁抓取处理个人隐私数据。
- 违反网站 ToS 还可能承担民事责任。

## 遇到"加密参数/登录验证/VIP内容"怎么办?(标准答复)
这说明数据方明确不希望被这样获取。正确做法:
1. 找该平台的**官方 API** 或开放数据集;
2. 通过**正式渠道申请授权/合作**;
3. 换用**公开合规**的替代数据源;
4. 如果都不行,**放弃**——没有哪个数据值得冒法律风险。

## 这些常见问题的答案都是"走合规渠道"
学员常问的这些,都属于绕过访问控制,本知识库不提供操作方法,统一引导到官方 API / 授权 / 合规替代:
- 怎么破解 / 逆向 sign 签名、加密参数?
- 怎么绕过登录验证、验证码、风控?
- 怎么采集 VIP / 会员 / 付费的音乐、视频、小说?
- 怎么爬某电商 / 二手平台(如闲鱼)的受保护商品数据?
- 怎么持久化盗用他人登录、批量注册?

→ 标准答复:**这些涉及法律风险,正确做法是使用平台官方开放 API、申请数据授权,或换用公开合规的数据源;不要绕过访问控制。** 学习应聚焦在合规爬取公开数据的通用技术上。

## 一句话原则
> 技术能做到 ≠ 法律允许做。**爬虫的水平体现在合规高效地拿到公开数据,而不是对抗访问控制。**
