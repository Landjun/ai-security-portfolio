# 闭包与作用域进阶

## 变量作用域有哪几层?
Python 按 LEGB 查找:Local(局部)→ Enclosing(外层函数)→ Global(全局)→ Built-in(内置)。
找到第一个就用,所以局部会"遮住"全局的同名变量。

## 函数里能读全局变量吗?能改吗?
能读;直接赋值会变成新建局部变量。要修改全局变量需 `global` 声明:
```
n = 0
def inc():
    global n
    n += 1
```
但尽量少用 global,优先用参数和返回值。

## 闭包是什么?
内层函数"记住"了外层函数的变量,即使外层已返回:
```
def make_counter():
    count = 0
    def counter():
        nonlocal count      # 修改外层变量需 nonlocal
        count += 1
        return count
    return counter

c = make_counter()
print(c(), c(), c())        # 1 2 3
```

## nonlocal 和 global 区别?
- global:操作模块级全局变量。
- nonlocal:操作"外层函数"的局部变量(用于闭包)。

## 闭包有什么用?
封装状态(如上面的计数器)、做装饰器、配置带记忆的函数。
