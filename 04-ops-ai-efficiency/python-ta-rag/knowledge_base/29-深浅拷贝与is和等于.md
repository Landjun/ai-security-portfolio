# 深浅拷贝、is 与 ==

## == 和 is 有什么区别?
- `==` 比较"值是否相等"。
- `is` 比较"是不是同一个对象"(内存地址相同)。
日常判断相等用 `==`;判断是否为 None 用 `is`:`if x is None:`。

## 为什么 b = a 改了 b,a 也变了?
对列表/字典等可变对象,`b = a` 只是让 b 和 a 指向同一个对象,改 b 就是改 a。
要得到独立副本需要拷贝。

## 浅拷贝怎么做?
`b = a[:]` 或 `b = a.copy()` 或 `copy.copy(a)`。
浅拷贝只复制最外层,如果元素里还有嵌套的列表,嵌套部分仍是共享的。

## 深拷贝怎么做?
```
import copy
b = copy.deepcopy(a)   # 连嵌套对象也完全复制,彻底独立
```
嵌套结构需要完全独立时用 deepcopy。

## 可变与不可变类型?
- 不可变:数字、字符串、元组(不能原地修改)。
- 可变:列表、字典、集合。
理解这点能避免很多"为什么我没改它却变了"的困惑。
