# 常用标准库

## 数学计算用什么?
`math` 模块:`math.sqrt(9)` 开方,`math.pi` 圆周率,`math.ceil/floor` 向上/向下取整。
随机数用 `random`:`random.randint(1,6)` 随机整数,`random.choice(列表)` 随机取一个。

## 处理日期时间用什么?
`datetime` 模块:
```
from datetime import datetime
now = datetime.now()                 # 当前时间
print(now.strftime("%Y-%m-%d %H:%M"))  # 格式化输出
```

## 操作文件路径用什么?
`os` 和 `pathlib`:
- `os.path.exists(路径)` 判断是否存在;`os.listdir(目录)` 列目录。
- 新代码推荐 `pathlib`:`from pathlib import Path; Path("a/b.txt").exists()`。

## 处理 JSON 用什么?
`json` 模块:`json.dumps(对象)` 转字符串,`json.loads(字符串)` 解析。

## 怎么知道一个模块有哪些功能?
`dir(模块)` 列出可用名称;`help(函数)` 看文档。多查官方文档是好习惯。
