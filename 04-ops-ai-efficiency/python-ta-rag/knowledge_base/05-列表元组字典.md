# 列表、元组、字典

## 列表 list 怎么用?
有序、可变的容器,用方括号:`nums = [1, 2, 3]`。
- 取元素:`nums[0]`(从 0 开始);最后一个:`nums[-1]`。
- 增:`nums.append(4)`;删:`nums.remove(2)` 或 `del nums[0]`。
- 长度:`len(nums)`;切片:`nums[1:3]`(取下标 1、2)。

## 列表和元组有什么区别?
列表用 [] 可修改;元组用 () 不可修改(适合存放固定不变的数据)。
`t = (1, 2, 3)` 创建元组,改 t[0] 会报错。

## 字典 dict 怎么用?
键值对,用花括号:`d = {"name": "小明", "age": 18}`。
- 取值:`d["name"]`;安全取值:`d.get("name")`(键不存在返回 None 而非报错)。
- 增改:`d["score"] = 90`;删:`del d["age"]`。
- 遍历:`for k, v in d.items():`。

## 报错 KeyError 是什么意思?
访问了字典里不存在的键。用 `d.get(键)` 或先 `if 键 in d:` 判断可避免。
