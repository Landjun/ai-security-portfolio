# 类与对象(面向对象入门)

## 怎么定义一个类?
```
class Student:
    def __init__(self, name, age):   # 构造方法,创建对象时自动调用
        self.name = name             # 实例属性
        self.age = age

    def say_hi(self):                # 实例方法
        print(f"我是{self.name}")

s = Student("小明", 18)   # 创建对象
s.say_hi()                # 调用方法
print(s.name)             # 访问属性
```

## self 是什么?
self 代表"当前这个对象自己"。定义实例方法时第一个参数必须是 self,
通过它访问对象的属性和其他方法。调用时不用手动传,Python 自动传入。

## __init__ 是什么?
构造方法,创建对象时自动执行,用来初始化对象的属性。

## 类和对象的关系?
类是"模板/图纸"(如 Student),对象是按模板造出来的"实例"(如具体的小明)。
一个类可以创建多个对象,各自有独立的属性。
