# 批量下载图片与文件

## 怎么把一张图片/文件下载保存到本地?
拿到资源链接后,用 requests 取二进制内容,以 "wb" 写入文件:
```
import requests
r = requests.get(img_url, timeout=10)
with open("pic.jpg", "wb") as f:
    f.write(r.content)        # content 是二进制
```

## 怎么批量下载(壁纸/小说图片下载器思路)?
1. 先爬列表页,解析出所有资源链接(见 BeautifulSoup 篇)。
2. 循环逐个下载,文件名用序号或标题。
```
import os, time
os.makedirs("downloads", exist_ok=True)
for i, url in enumerate(urls):
    r = requests.get(url, timeout=10)
    with open(f"downloads/{i}.jpg", "wb") as f:
        f.write(r.content)
    time.sleep(1)             # 每次间隔,降低频率
```

## 文件名怎么取(避免重复/非法字符)?
用序号最稳妥;若用标题,要去掉 `\ / : * ? " < > |` 等非法字符。

## 翻页批量怎么做?
观察 URL 翻页规律(如 `?page=1`、`?page=2`),用循环拼接页码:
```
for page in range(1, 6):
    url = f"https://example.com/list?page={page}"
    ...
```

## 注意
只下载**有权下载、允许使用**的资源;控制频率,尊重版权(图片/小说多受著作权保护)。
