# Pandas 数据筛选与处理

## 怎么按条件筛选行?
用布尔条件:
```
df[df["分数"] >= 90]                 # 分数大于等于90的行
df[(df["分数"] >= 60) & (df["分数"] < 90)]   # 多条件用 & |,每个条件加括号
```

## loc 和 iloc 区别?
- `df.loc[行标签, 列名]`:按标签/列名取,如 `df.loc[0, "分数"]`。
- `df.iloc[行号, 列号]`:按整数位置取,如 `df.iloc[0, 1]`。

## 怎么新增/修改一列?
```
df["是否及格"] = df["分数"] >= 60        # 新增一列
df["分数"] = df["分数"] + 5             # 整列加分
```

## 怎么处理缺失值?
- 查看:`df.isnull().sum()` 统计每列缺失数。
- 删除:`df.dropna()` 删有缺失的行。
- 填充:`df.fillna(0)` 用 0 填,或 `df["列"].fillna(df["列"].mean())` 用均值填。

## 怎么排序?
```
df.sort_values("分数", ascending=False)   # 按分数降序
```

## SettingWithCopyWarning 是什么?
对筛选出来的"切片"赋值时的警告。规范做法:用 `.loc` 一次性定位再赋值,
如 `df.loc[df["分数"]<60, "评级"] = "不及格"`。
