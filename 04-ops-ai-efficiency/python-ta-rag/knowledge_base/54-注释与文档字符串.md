# 注释与文档字符串

## 怎么写注释?
- 单行注释用 `#`,从 # 到行尾都是注释,不会被执行:
```
x = 10   # 这是行内注释
```
- 多行说明可以连续写多行 #,Python 没有专门的多行注释语法。

## 注释要写什么?
解释"为什么这么做",而不是复述代码字面意思。好的代码 + 关键处注释最佳。

## 文档字符串(docstring)是什么?
写在函数/类/模块开头的三引号字符串,用来说明用途:
```
def add(a, b):
    """返回 a 和 b 的和。"""
    return a + b

print(add.__doc__)   # 查看文档字符串
help(add)            # 也会显示它
```

## 临时屏蔽代码怎么做?
在行首加 `#` 注释掉。多数编辑器选中后按 Ctrl + / 可批量注释/取消。

## TODO 注释有什么用?
`# TODO: 这里以后要优化`,标记待办,很多编辑器能高亮和汇总 TODO。
