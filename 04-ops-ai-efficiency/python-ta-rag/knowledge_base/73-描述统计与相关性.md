# 描述统计与相关性分析

## 怎么快速看数据的整体情况?
```
df.describe()        # 数值列的计数/均值/标准差/最小/四分位/最大
df["分数"].mean()    # 均值
df["分数"].median()  # 中位数
df["分数"].std()     # 标准差(衡量离散程度)
df["分数"].mode()    # 众数(出现最多的值)
```

## 均值和中位数怎么选?
数据有极端值(如个别超高薪资)时,中位数更能代表"中间水平",均值会被拉高。
分析薪资、房价这类常看中位数。

## 怎么看某列的分布?
- `df["城市"].value_counts()`:每个取值出现的次数。
- 画直方图:`df["分数"].plot(kind="hist")`。

## 相关性怎么算?
```
df.corr()                     # 各数值列两两相关系数矩阵
df["广告费"].corr(df["销量"]) # 两列的相关系数
```
相关系数在 -1 到 1 之间:接近 1 正相关,接近 -1 负相关,接近 0 几乎无线性关系。

## 相关 ≠ 因果(重要)
两个变量相关,不代表一个导致另一个。分析时别把"相关"当"因果",
可能有第三个隐藏因素,或纯属巧合。

## 分析报告的常见指标?
总量、均值/中位数、最大最小、分布占比、同比/环比、相关性——按业务问题选用。
