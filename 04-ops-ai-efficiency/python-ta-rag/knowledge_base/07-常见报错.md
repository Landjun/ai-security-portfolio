# 常见报错及解决

## NameError: name 'xxx' is not defined
变量或函数没定义就使用了。常见原因:拼写错误、变量定义在使用之后、忘了赋值。
检查变量名拼写,确认它在使用前已经赋值。

## TypeError
类型用错了。例如字符串和数字直接相加 `"10" + 5`,或对不可调用对象用了 ()。
看报错说明,通常会指出哪两个类型不兼容,按需做类型转换。

## ModuleNotFoundError: No module named 'xxx'
导入了没安装的库。解决:`pip install xxx`。
注意区分:有时是文件名/模块名写错,或没在正确的虚拟环境里安装。

## IndexError: list index out of range
列表下标越界,访问了不存在的位置。例如列表只有 3 个元素却访问 nums[5]。
检查下标范围,记住下标从 0 开始,最后一个是 len(nums)-1。

## ZeroDivisionError
除数为 0。在做除法前判断分母是否为 0。

## 读不懂报错怎么办?
把最后一行(错误类型 + 说明)复制去搜索,绝大多数报错都有现成答案;
同时看 line 行号定位到自己代码的具体位置。
