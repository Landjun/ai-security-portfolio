# 布尔与真假值判断

## 布尔值是什么?
只有两个:True 和 False(注意首字母大写)。比较和逻辑运算的结果就是布尔值。

## 哪些值被当作"假"?
在 if 判断里,这些都相当于 False:
- `False`、`None`
- 数字 `0`、`0.0`
- 空字符串 `""`、空列表 `[]`、空字典 `{}`、空集合 `set()`、空元组 `()`
其余非空、非零的值都当作 True。

## 怎么利用真假值简化判断?
```
names = []
if names:            # 空列表为假,等价于 if len(names) > 0
    print("有数据")
else:
    print("列表是空的")
```

## and / or 的返回值是什么?
不一定是 True/False,而是返回决定结果的那个操作数:
- `a or b`:a 为真返回 a,否则返回 b。常用于设默认值:`name = name or "匿名"`。
- `a and b`:a 为假返回 a,否则返回 b。

## not 怎么用?
`not x` 取反:`if not names:` 表示"如果列表为空"。

## 链式比较?
`if 0 < x < 100:` 等价于 `0 < x and x < 100`,Python 支持这种简洁写法。
