# 字典进阶用法

## 怎么安全地取值,避免 KeyError?
- `d.get("key")`:键不存在返回 None,不报错。
- `d.get("key", 默认值)`:键不存在返回指定默认值。
- 先判断:`if "key" in d:`。

## 怎么遍历字典?
- 遍历键:`for k in d:` 或 `for k in d.keys():`
- 遍历值:`for v in d.values():`
- 同时遍历键值:`for k, v in d.items():`(最常用)

## 怎么合并两个字典?
- Python 3.9+:`d1 | d2`
- 通用写法:`d1.update(d2)`(把 d2 合并进 d1)

## 统计计数有什么简便方法?
用 `collections.Counter`:
```
from collections import Counter
c = Counter("abracadabra")
print(c["a"])   # 统计 a 出现次数
```

## 字典的键有什么要求?
键必须是不可变类型(字符串、数字、元组),列表不能当键。值可以是任意类型。
