# 爬虫中的编码问题

## 爬下来的中文乱码怎么办?
requests 有时猜错编码。手动指定:
```
r = requests.get(url)
r.encoding = "utf-8"     # 或 "gbk",看网页实际编码
print(r.text)
```

## 怎么知道网页是什么编码?
- 看网页 `<meta charset="utf-8">`。
- 看响应头 `r.headers.get("Content-Type")`。
- 用 `r.apparent_encoding` 让 requests 猜测真实编码:
```
r.encoding = r.apparent_encoding
```

## 保存文件时乱码?
写文件时显式指定 `encoding="utf-8"`;给 Excel 用的 CSV 用 `utf-8-sig`。

## str 和 bytes 搞混导致报错?
- `r.text` 是已解码的字符串(str)。
- `r.content` 是原始字节(bytes),下载图片/文件用它。
需要时手动转:`r.content.decode("utf-8")`。

## URL 里有中文怎么办?
用 `requests` 的 params 传参会自动编码;手动编码用:
```
from urllib.parse import quote
quote("壁纸")     # 转成 %xx 形式
```

## 常见报错 UnicodeDecodeError?
解码用错编码了。先确认网页真实编码,再用对应编码解码;不确定时试 utf-8 / gbk。
