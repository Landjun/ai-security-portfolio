# 爬虫稳定性与异常处理

## 爬虫为什么经常中途报错?
网络不稳定、超时、目标页面结构变化、被限流等都会让程序崩。
稳定的爬虫要能"出错不崩、能重试、能跳过坏数据"。

## 怎么加超时和异常处理?
```
import requests
try:
    r = requests.get(url, timeout=5)
    r.raise_for_status()       # 状态码非 200 会抛异常
except requests.RequestException as e:
    print("请求失败:", e)
```
永远给请求加 `timeout`,否则可能永久卡住。

## 怎么自动重试?
```
import time
for attempt in range(3):
    try:
        r = requests.get(url, timeout=5)
        break
    except requests.RequestException:
        time.sleep(2)          # 等一会再试
else:
    print("重试多次仍失败,跳过")
```

## 怎么避免一条坏数据让整个程序停?
在循环里对每条单独 try/except,出错就记录并 continue,保证其余继续:
```
for url in urls:
    try:
        process(url)
    except Exception as e:
        print("跳过", url, e)
        continue
```

## 被限流/封禁了怎么办?
**降低频率**(加大 sleep)、减少并发、回归合规访问。不要用更激进的方式对抗风控——
那既可能违规,也治标不治本。

## 怎么记录进度,避免重复爬?
把已处理的 URL 存到文件/集合里,重启时跳过已完成的,做到断点续爬。
