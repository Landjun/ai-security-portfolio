# 类的继承与封装

## 继承怎么写?
子类括号里写父类名,即可继承父类的属性和方法:
```
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        print("...")

class Dog(Animal):          # Dog 继承 Animal
    def speak(self):        # 重写方法
        print(f"{self.name}: 汪汪")

Dog("旺财").speak()
```

## super() 是什么?
调用父类的方法,常用于在子类构造方法里先初始化父类:
```
class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name)   # 调父类 __init__
        self.color = color
```

## 什么是多态?
不同子类对同一方法有各自实现,调用时表现不同。比如都调 speak(),
Dog 输出"汪汪"、Cat 输出"喵喵"。

## 私有属性怎么写?
属性名前加两个下划线表示"私有",外部不应直接访问:
```
class Account:
    def __init__(self):
        self.__balance = 0      # 私有
```
这叫封装:把内部细节藏起来,只通过方法暴露受控的接口。

## 类属性和实例属性区别?
类属性定义在类里、所有实例共享;实例属性在 __init__ 里用 self 定义、每个对象独立。
