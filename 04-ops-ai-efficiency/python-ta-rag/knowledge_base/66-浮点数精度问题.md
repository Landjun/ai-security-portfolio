# 浮点数精度问题

## 为什么 0.1 + 0.2 不等于 0.3?
```
print(0.1 + 0.2)        # 0.30000000000000004
print(0.1 + 0.2 == 0.3) # False
```
计算机用二进制存浮点数,很多十进制小数无法精确表示,会有微小误差。这是所有语言的通病。

## 怎么正确判断两个浮点数"相等"?
不要用 ==,而是看差值是否足够小:
```
import math
math.isclose(0.1 + 0.2, 0.3)   # True
# 或:abs(a - b) < 1e-9
```

## 涉及金额/精确计算怎么办?
用 decimal 模块,避免误差:
```
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3
```
注意要用字符串构造 Decimal("0.1"),不要用 Decimal(0.1)。

## 怎么按需四舍五入显示?
显示时用 `round(x, 2)` 或 f-string `f"{x:.2f}"` 控制小数位。

## 一句话总结
浮点有误差是正常现象;判断相等用 math.isclose,精确计算用 Decimal。
