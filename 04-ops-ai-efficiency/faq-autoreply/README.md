# 案例:教学/运营 FAQ 自动回复

> `04 运营 AI 提效` 案例。把高频重复咨询用自动回复挡掉,人工只处理兜底问题。离线规则版,零依赖可跑。

## 1. 业务痛点

教学/运营每天被大量**重复问题**淹没(怎么报名、能不能退款、什么时候上课……),
占用大量人工时间,响应还慢。

## 2. AI/自动化方案

先用**关键词规则**做一个自动回复助手:命中高频问题直接给标准答复,
未命中的转人工兜底。这是最小可用版(MVP),成本低、当天就能上线。

> 进阶:把关键词匹配换成 **RAG / 大模型语义匹配**(见 [06 真实 RAG](../../06-ai-development/real-rag-system/)),
> 可处理换一种问法的同义问题,命中率更高。

## 3. 效果

- 演示 8 条咨询,自动回复命中 7 条(≈88%),仅 1 条转人工。
- 估算:每天 100 条咨询,可自动处理约 88 条,人工工作量大幅下降。

## 4. 可复用模板

- `RULES`:把你业务的高频问题 + 标准答复填进去即可。
- `FALLBACK`:兜底话术,引导用户走人工或给出菜单。

## 5. 运行 & 验证


## 6. 作品集/面试表达

> "我给教学运营做了一个 FAQ 自动回复助手:先用关键词规则把报名、退款、上课时间这类高频问题自动答掉,命中率约 88%,人工只处理兜底问题,大幅降低重复咨询的人力。我能讲清它的演进路线——从规则版到 RAG 语义版,以及如何用命中率量化提效。这体现了我把 AI/自动化落到真实业务、用数据说明价值的能力。"

## 安全/合规

标准答复内容由运营审核;涉及金额/政策以官方口径为准;不收集用户敏感信息。
