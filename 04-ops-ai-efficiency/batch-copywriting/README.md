# 案例:DeepSeek 批量文案生成

> `04 运营 AI 提效` 案例。用大模型为多个课程/活动批量生成推广文案,运营从"写"变成"挑"。复用 06 的 DeepSeek key;无 key 时自动降级离线模板,保证可演示。

## 1. 业务痛点

运营每天要为多个课程/活动写朋友圈、短视频、海报文案,**耗时、风格不稳定、产能受限**。

## 2. AI 方案

用统一的 prompt(风格、字数、emoji、卖点要求)让 DeepSeek **批量生成多主题、多条**文案,
人工只做挑选与微调。把创作的"从 0 到 1"交给 AI,人专注"从 1 到优"。

## 3. 效果

- 一次为 3 个主题各生成 3 条小红书风格文案(共 9 条),秒级完成。
- 运营工作从"逐条写"变成"批量挑",产能成倍提升,风格更统一。

## 4. 工程要点(可复用)

- **复用密钥**:从 `06-ai-development/real-rag-system/.env` 读 `DEEPSEEK_API_KEY`,不重复配置、不提交密钥。
- **优雅降级**:未检测到 key 或调用失败时,自动切换离线模板,保证流程不中断、随时可演示。
- **参数化**:`TOPICS` 和 `STYLE` 抽出来,换业务只改这两处。

## 5. 运行 & 验证

```powershell
cd 04-ops-ai-efficiency\batch-copywriting
python generate.py
```
预期:有 key 时走 DeepSeek 在线生成;无 key 时走离线模板。两种都能输出每个主题的多条文案。

## 6. 作品集/面试表达

> "我用 DeepSeek 给运营做了一个批量文案生成工具:用统一 prompt 约束风格、字数和卖点,一次为多个课程批量出多条文案,运营从逐条写变成批量挑,产能成倍提升。工程上我做了密钥复用和优雅降级——没有 API key 时自动切离线模板,保证演示和流程不中断。这体现我能把大模型真正落到运营业务、并考虑工程鲁棒性。"
