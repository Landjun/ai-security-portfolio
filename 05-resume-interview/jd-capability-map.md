## 二、6 项重点能力(JD 详述)逐条对应

- 关键差异化:**在真实 DeepSeek 上验证**,不是只在模拟模型。

### 能力2 网络攻防红蓝队 🟡
- 8 个 Web 漏洞本地复现(SQLi/XSS/命令注入/路径穿越/SSRF/上传/反序列化/SSTI)+ 红蓝队方法论文档。
- 诚实缺口:无真实渗透/内网/演练经历 → 计划用授权靶场 + SRC 补。

### 能力3 漏洞挖掘与代码审计 🟡
- AI Agent 代码审计案例:7 类漏洞 + 静态扫描器 + 人工审计报告 + AI 辅助审计。
- 诚实缺口:无真实 CVE/CNVD/CNNVD 编号 → 计划上 SRC 平台积累。

### 能力4 AI Native / Agent 开发 🟢
- Python 全栈;真实 RAG(embedding+检索+生成)、function-calling Agent、**LangChain** Agent、安全网关。
- 小缺口:TypeScript 未覆盖(Python 已充分)。

### 能力5 AI 系统安全评测体系 🟢
