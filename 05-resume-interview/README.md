## 投递三件套(均已就绪)

1. **GitHub 作品集**:github.com/Landjun/ai-security-portfolio
2. **技术文章**:见 [articles/](../articles/)(6 篇,含发布指南)

## 怎么用

- 投递:用 resume-project-section(标准版)+ hr-outreach(打招呼)。
- 面试:对照 project-map 的 STAR 故事练 2-3 个;用 talk-deck 的口播稿。
- 针对岗位:用 jd-gap-analysis / jd-capability-map 对齐侧重。

> **作品集的最终出口在这里——但真正的出口,是你按下"投递"按钮的那一下。**
