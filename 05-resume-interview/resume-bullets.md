# 简历项目要点 (Resume Bullets)

> 每完成一个案例，就在这里追加一条「可直接写进简历」的话术。作品集 → 简历的转换器。

## 项目总述（一句话介绍整个作品集）

> 独立搭建 AI 安全作品集仓库，按「原理→复现→防护→修复→检测→面试表达」六步法沉淀，已完成提示注入、越狱、RAG 注入检测 3 个可运行攻防案例，全部纯 Python、零依赖、本地可复现，对应 OWASP LLM Top 10。

## 案例话术

### 1. 提示注入 (Prompt Injection) · [代码](../02-ai-security/prompt-injection/)
> 独立完成提示注入最小复现与防御 Demo：用模拟大模型还原"数据冒充指令"劫持模型、泄露系统提示词的攻击路径，并实现基于特征的输入护栏成功拦截，自测 100% 通过；能讲清 OWASP LLM01 原理及输入护栏 / 指令数据分离 / 最小权限 / 输出过滤的多层防御。

### 2. 越狱 (Jailbreak) · [代码](../02-ai-security/jailbreak/)
> 完成越狱攻防最小复现：模拟带安全对齐的模型，还原角色扮演 / 假设虚构 / DAN 等护栏绕过手法，并在应用层实现四类越狱话术检测 + 拒答加固，自测 100% 通过；能区分越狱与提示注入，并阐述"不能只依赖模型自带护栏、需在输入输出两端做双向防御"的工程思路。

### 3. RAG 注入检测器 (RAG Injection Detector) · [代码](../03-agent-rag-security/rag-injection-detector/)
> 独立开发 RAG 注入检测器，复现并防御 RAG 特有的"间接提示注入"：向知识库植入带隐藏指令的文档，演示天真 RAG 检索后被劫持泄露管理员密钥；实现可扫描文档/文件的检测器（5 类注入特征、入库前+检索后双重关卡），自测 100% 通过；能阐述间接注入与普通注入的差异及来源分级、指令数据分离等防护，对应 OWASP LLM01/LLM03。

### 4. Agent 工具调用权限审计 (Tool-Call Permission Audit) · [代码](../03-agent-rag-security/tool-permission-audit/)
> 独立开发 Agent 工具调用权限审计器，针对 OWASP LLM06 过度授权：模拟被劫持的 Agent 发起越权转账、删库、任意 shell 等高危调用，实现最小权限审计关卡——白名单默认拒绝、只读放行、资金/对外动作挂起人工确认、参数越界（如转账超限）即拦截，自测 6/6 通过；能阐述 Agent 安全的重点从"模型说什么"转向"Agent 能做什么"，及最小权限、参数约束、人审高危、审计日志的工程化防护。

### 5. 端到端安全 Agent 管线 (Secure Agent Pipeline) · [代码](../03-agent-rag-security/secure-agent-pipeline/)
> 将 RAG 注入检测器与工具调用审计器组合成端到端安全 Agent 管线，演示纵深防御：复现"污染知识库做间接注入→劫持 Agent→发起越权转账"的完整攻击链，设计三档对比场景证明任一层失守另一层仍能兜底（输入护栏失守时动作审计仍拦下越权转账）；能阐述安全能力应做成可复用的拦截器中间件、不依赖单点防御，对应 OWASP LLM01+LLM06 组合防御。

### 6. 真实 RAG 系统 (AI 开发) · [代码](../06-ai-development/real-rag-system/)
> 独立搭建真实可用的 RAG 问答系统：本地 fastembed 中文 embedding（bge-small-zh）做语义检索 + DeepSeek 大模型生成，余弦相似度 top-k 召回；检索与生成解耦以平衡成本与质量，实测语义检索准确、回答有据可依无幻觉。打通向量化→检索→增强→生成完整链路。

### 7. 真实 LLM 注入攻防验证 (AI 开发 × AI 安全) · [代码](../03-agent-rag-security/real-rag-injection/)
> 在真实 DeepSeek RAG 上复现并防御间接提示注入：实测无防护时大模型被知识库隐藏指令劫持、泄露仅存于投毒文档的暗号；接入注入检测器后于源头剔除投毒文档、防御成功。研究中发现 v1 正则检测器被"换措辞"绕过（[系统]→[系统提示]、规则→限制），据此加固至 v2 并补充变体测试，进而提出升级 ML 语义检测的路线——完整呈现"攻击→防御失败→定位根因→加固→再验证"的安全研究方法论。

### 8. 真实 Agent (DeepSeek Function Calling) · [代码](../06-ai-development/real-agent/)
> 用 DeepSeek function calling 搭建真实客服 Agent，实现完整的工具调用循环（工具选择→本地执行→结果回填→生成答案）；模型自主完成多工具推理（退款前先查订单与政策再请求确认）。并提出关键安全洞察：模型的自觉不等于保证，工具执行前必须加硬性权限审计，将 AI 开发能力与 Agent 过度授权（OWASP LLM06）防护打通。

### 9. 文本对抗样本与对抗训练 (AI 内生安全) · [代码](../07-ai-intrinsic-security/text-adversarial/)
> 在模型层(而非提示层)做攻防：用 scikit-learn 训练字符级垃圾短信分类器，以形近字替换+拆字分隔构造对抗样本，在人类语义不变下将模型判定从"垃圾 0.63"翻转为"正常 0.49"，绕过检测；防御上对比输入规范化（治标）与对抗训练（治本），对抗训练后模型自身可识别对抗样本（0.78）。能区分对抗样本与提示注入，阐述对抗训练为 AI 内生安全核心手段，对应 MITRE ATLAS / OWASP ML Top 10。

### 10. 数据投毒攻防 (AI 内生安全) · [代码](../07-ai-intrinsic-security/data-poisoning/)
> 复现训练阶段的数据投毒：用标签翻转（垃圾标成正常）仅 6 条毒样本即把分类器测试准确率从 100% 拉低到 62%；用 kNN 标签一致性检测揪出毒样本（6/6）、清洗重训恢复至 100%。并发现"雷同毒样本抱团可逃避近邻检测"的攻防细节，据此阐述训练数据来源可信与标注审计比后置检测更根本，对应 OWASP LLM03 / MITRE ATLAS。

### 11. 后门/木马攻击与自动触发器扫描 (AI 内生安全) · [代码](../07-ai-intrinsic-security/backdoor-attack/)
> 复现隐蔽的文本后门：通过投毒埋入秘密触发器，模型干净测试集准确率仍达 100%（极隐蔽），但输入含触发器"蓝月亮"时垃圾被放行（垃圾概率 0.79→0.17）。防御实现自动触发器扫描（翻转测试：枚举字符片段并测量其对垃圾概率的集体拉低，触发器以 +0.55 远超其他片段被自动揪出），再以输入净化使后门失效。能讲清后门与普通投毒的区别及上线前后门扫描的必要性，对应 OWASP LLM03 / MITRE ATLAS。

### 12. 成员推断攻击与隐私防护 (AI 内生安全·隐私) · [代码](../07-ai-intrinsic-security/membership-inference/)
> 复现成员推断攻击（MIA）：利用"模型对训练样本更自信"的信号判断某条数据是否在训练集中——敏感数据场景即隐私泄露。过拟合随机森林上攻击 AUC 达 0.93、准确率 86%；用正则化抑制过拟合后成员/非成员自信度差异几乎消失，AUC 降至 0.56（接近随机）。提出"过拟合即隐私风险"的核心洞察及差分隐私训练（DP-SGD）、置信度脱敏、查询限制等防护，对应 MITRE ATLAS 与数据隐私合规。

### 13. 模型窃取攻防 (AI 内生安全) · [代码](../07-ai-intrinsic-security/model-extraction/)
> 复现黑盒模型窃取：仅用查询拿到的输入-输出对训练替身模型，1400 次查询后替身与受害者预测一致率（保真度）达 95%、真实准确率追平至 88%，无需知道架构与训练数据即完整复制模型功能。防御演示查询限流（预算砍到 50→保真度 88%）与输出扰动（加噪 30%→保真度 91%），核心洞察"能被查询就能被学习，黑盒不等于安全"，并提出模型水印事后举证，对应 OWASP LLM 模型窃取 / MITRE ATLAS。

### 14. 自动化红队基准 (AI 内生安全) · [代码](../07-ai-intrinsic-security/auto-redteam/)
> 构建自动化红队框架量化自有注入/越狱检测器的鲁棒性：6 条攻击种子 × 6 种变形手法生成 36 个变体，自动测出总体绕过率 31%（安全得分 69%），并精准定位"拆字分隔"手法 100% 绕过为最致命弱点。把安全从主观判断变成可追踪、可回归的指标（每次加固后重跑验证绕过率下降），印证正则检测脆弱、需 ML 语义检测，对应工业界 LLM 红队评测 / MITRE ATLAS。

### 15. ML 语义注入检测器 (AI 开发 × 安全 · 工程化) · [代码](../03-agent-rag-security/ml-injection-detector/)
> 将脆弱的正则注入检测器升级为语义 ML 检测器（fastembed 中文 embedding + 逻辑回归 + 输入规范化）。在自动化红队的同一套 36 个攻击变体上，正则绕过率 53%，ML 检测器降至 0%、拦截率 100% 且零误报——而攻击变体与正常请求均未参与训练（真实泛化）。完整闭合"手动发现绕过→红队量化→语义模型根治"的安全工程闭环，对应 Roadmap 3.1。

### 16. 真实 Agent 越权攻防 (AI 开发 × 安全) · [代码](../03-agent-rag-security/real-agent-audit/)
> 将权限审计器接入真实 DeepSeek function-calling Agent 的工具执行前。诚实呈现：面对"退款99999元"恶意请求，DeepSeek 这次自行拒绝——但指出这是模型自觉而非保证；进而模拟被劫持、强行发起调用的 Agent：无审计时 99999 元退款被真实执行，接入审计器后超限退款在执行前被拦截、正常小额退款也挂起人工确认。与 RAG 注入检测器组合形成"输入防注入+执行控权限"的纵深防御，对应 OWASP LLM01+LLM06。

### 17. LLM 安全网关 (工程化收口) · [代码](../03-agent-rag-security/llm-security-gateway/)
> 将作品集中所有安全检测器封装成统一拦截中间件：输入护栏（注入+越狱检测）、动作审计（工具最小权限）、输出扫描（机密/系统提示词泄露），三道关卡 + 全链路审计日志，并用 Python 标准库暴露为 HTTP API（POST /check），任意应用零依赖接入即获纵深防御。各关卡检测器可插拔升级（输入护栏可换成 ML 语义检测器）。体现"安全能力应是可插拔统一中间件"的工程理念，对应 Roadmap 3.2。

### 18. 差分隐私训练 DP-SGD (AI 内生安全·隐私·研究向) · [代码](../07-ai-intrinsic-security/dp-sgd/)
> 用 numpy 手写 DP-SGD（逐样本梯度裁剪 + 高斯噪声，对应 Abadi 2016），从训练阶段闭环成员推断攻击。扫描噪声强度量化隐私-效用权衡：随 σ 增大，成员推断 AUC 从 0.58 降至 0.51（≈随机，几乎不泄露），测试准确率从 81% 降至 63%（隐私代价）。并验证"训练步数过多会消耗隐私预算、使噪声失效"的细节，提出按数据敏感度选择 ε 预算的工程权衡。

### 19. 传统 Web 安全四件套 (传统安全) · [代码](../01-traditional-security/)
> 本地靶场复现并防御四类经典漏洞:SQL 注入(`admin' --` 绕过登录 → 参数化查询)、XSS(脚本注入 → 输出转义)、命令注入(`&&` 追加命令 → 参数列表+shell=False)、路径穿越(`../` 越界读机密 → 规范化+边界校验)。每个都有"不安全 vs 安全"可运行对比,对应 OWASP Top 10 A01/A03,支撑"从传统安全转型 AI 安全"的完整叙事。

### 20. 运营 AI 提效 (业务落地) · [代码](../04-ops-ai-efficiency/)
> 把 AI/自动化落到真实运营业务:FAQ 自动回复(关键词规则自动答高频咨询、量化命中率提效)、DeepSeek 批量文案生成(多主题批量产出、密钥复用 + 无 key 优雅降级)。体现把大模型用于真实业务、以数据说明价值并兼顾工程鲁棒性的能力。

### 21. Python 答疑助教 RAG 知识库 (AI 开发 × 安全 × 业务落地 · 旗舰) · [代码](../04-ops-ai-efficiency/python-ta-rag/)
> 构建可替代助教的 Python 答疑智能客服(命令行 + 网页两种界面),知识库 53 篇 markdown 贴合真实爬虫课程大纲(基础→进阶→爬虫→数据分析→求职,运营可自助扩充)。本地 fastembed 向量化 + 落盘缓存秒级启动,语义检索 top-3 由 DeepSeek 基于资料作答并标注来源。**四道可信护栏**:超纲拒答(防幻觉)+ 安全护栏(复用自研 LLM 安全网关拦截提示注入/越狱)+ **合规护栏**(规则识别"破解/逆向/绕过/采集VIP付费"类意图,不教绕过访问控制、直接给合规引导)+ 引用溯源。实测正常答疑命中准确、对无关问题拒答、对注入与违规意图拦截。把真实 RAG 工程与 AI 安全/合规能力落到同一个有业务价值的产品里。
